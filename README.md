# Сайт Kinea

Одностраничный сайт-визитка Kinea: анализ движения без датчиков и маркеров на теле, реабилитация в стационаре и на дому.
Статика без сборки — `index.html` со стилями и скриптами внутри, изображения и видео в `assets/`.

Сайт: https://peretyaginmstu-jpg.github.io/kinea-site/

## Посмотреть локально

```bash
python3 -m http.server 4173
```

После этого сайт открыт на http://localhost:4173/. Можно и просто открыть `index.html` в браузере.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | Вся страница: разметка, стили, скрипты |
| `assets/pose-*.webp` | Кадры со скелетом и углами суставов |
| `assets/motion.webm`, `assets/motion.mp4` | Запись отслеживания движения, без звука |
| `assets/motion-poster.webp` | Первый кадр записи, виден до начала воспроизведения |
| `assets/ui-avatar.webp`, `assets/ui-strip.webp` | Концепты интерфейса |
| `assets/report.webp` | Пример отчёта с демоданными |
| `tools/check.mjs` | Проверка страницы перед выкладкой |
| `.github/workflows/release.yml` | Выкладка сайта при публикации релиза |

## Контакты

Контакты вписываются в одном месте — в блоке визитки в конце `index.html`:

```html
<dl class="card__contacts">
  <dt>Контакты</dt>
  <dd>Скоро появятся на этой странице</dd>
</dl>
```

Пока там стоит строка-заглушка: в исходной презентации контактов не было.

## Схема на первом экране и анимации

Скелет на первом экране — не запись, а небольшая модель: одна поза считается в трёх измерениях и показывается в двух проекциях, спереди и сбоку.
Углы у суставов и значение на шкале вычисляются из той же позы. Ползунок «Глубина приседа» ставит показ на паузу и меняет позу вручную.

Остальные эффекты — «пол» из точек под первым экраном, появление блоков при прокрутке, наклон за курсором — описаны в конце `index.html`.
Если в системе включено «уменьшение движения», страница показывается без анимаций, а схема и видео запускаются только кнопкой «Пуск».

## Проверка

```bash
node tools/check.mjs
```

Скрипт проверяет, что файлы, на которые ссылается страница, на месте, что ссылки на разделы ведут на существующие якоря
и что встроенные скрипты разбираются без синтаксических ошибок.

## Выкладка

Сайт выкладывается на GitHub Pages экшном «Релиз сайта» — он запускается, когда на GitHub публикуется релиз:

```bash
gh release create v1.1.0 --generate-notes
```

Экшн проверяет страницу, собирает сайт, прикладывает к релизу архив `kinea-site-<версия>.zip` и обновляет страницу.
Запустить выкладку без нового релиза можно вручную со вкладки Actions.

## Оговорки

Kinea — ассистивный инструмент анализа движения, не медицинское изделие. Измеряет и показывает; диагноз и лечение определяет врач.
Изображения интерфейса на сайте — концепты, кадры со скелетом — иллюстративная реконструкция, пример отчёта содержит демоданные.
